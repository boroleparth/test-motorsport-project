How accurate is it

Every prediction here was made using only information available before the race (or before that lap), then compared with what actually happened. Settings are chosen on older seasons and tested on newer ones.

Track record

Forecasts saved on each race weekend, before qualifying and again before the race, then scored against the result. Every forecast is committed to GitHub before the session it predicts, so the history shows it was not changed afterwards.

Chance: the probability the forecast gave the eventual winner. Hover a forecast for its top three and when it was saved; the race name links to the saved file.
